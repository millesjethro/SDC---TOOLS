Instructions
  • For Post and Posts + Comments, open each post in its own tab. Use Landing Page for general pages or Profile Information for supported profiles.
  • File Name is optional. Leave it blank to use the extension's normal automatic name. If two rows end up with the same final name, later ones are saved as "name (2)", "name (3)", and so on, so nothing gets overwritten.
  • Turn on Use short platform prefixes to use FB, IG, TT, or X in automatic filenames.
  • Open the pages you want to capture in one Chrome window, then open Bulk Mode from that window. Bulk Mode lists web tabs in order and captures them from left to right.
  • Keep All Same on to use one capture mode for every tab. Turn it off to choose a mode beside each tab.
  • Timeline landing captures the landing view of a supported profile. Timeline captures successive screenshots until the timeline ends or reaches Max Shots (10 by default).
  • Turn on Metadata (saved as .txt) to save capture details in a text file named after the screenshot. A Timeline run saves one text file per tab, named after its first screenshot and listing all screenshots for that tab.
  • Keep the capture window visible while you work in a separate Chrome window.
  • Cancel stops a run after its current step finishes. Exit closes this window.
